## Typer av objekt

Exempel på `Person`-objekt finns i [Linked Arts dokumentation](https://linked.art/model/actor/). Observera att K-samsöks [krav på attribut](../informationsmodell/04-krav-pa-attribut.md) också gäller. > [!NOTE]
> **Utkast.** Exempel på minimala och rikare objekt av vanliga typer (till exempel `Person`, `HumanMadeObject` och `VisualItem`) ska läggas till, liksom exemplariska kompletta poster.
