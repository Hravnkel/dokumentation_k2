# Changelog

## 0.2

Typ av ändring: Sprintbaslinje (+0.1)

Ändringar:

- Fastställt dokumentet som baslinje för nästa sprint.
- Genomfört en innehållskontroll mot de ursprungliga beståndsdelarna som användes för version 0.1.
- Bekräftat att centralt sakinnehåll om grundprinciper, serialisering, kortformer, identitet, minimikrav, proveniens, rättighetsmärkning, vanliga mappningsmönster, klassificering, rekommenderade vokabulärer och datasetbeskrivning finns kvar.
- Bekräftat att borttaget innehåll huvudsakligen består av dubbelrubriker, duplicerad text, termlisteutkast och redaktionella platshållare.
- Termlistan ingår inte i baslinjen och behöver hanteras separat, sannolikt som bilaga eller eget dokument.
- Den engelska dubbletten av avsnittet om kortformer ingår inte i baslinjen.
- Platshållaren `Kom igång` för datasetbeskrivning ingår inte i baslinjen; behovet av instruktioner för adminportalen kvarstår som dokumentationslucka.
- Platshållaren om mappningskrav för vokabulärer ingår inte som eget avsnitt; frågan kvarstår som dokumentationslucka.
- Normaliserat rubrikhierarkin och den löpande kapitelnumreringen.
- Ingen ny teknisk sakinformation har lagts till.
