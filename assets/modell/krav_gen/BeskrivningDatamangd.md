# Beskrivning av datamängder

K-samsök levererar metadata till bl a det gemensamma europeiska dataområdet för kulturarv (Europeana), [Sveriges dataportal](https://www.dataportal.se/) och [European data](https://data.europa.eu/). För att datamängderena som levereras ska vara hittbara för användare krävs information om deras innehåll och proviniens. Beskrivningen är baserad på DCAT-AP SE (och Europeana datasheets ?).
